# Evaluation Rubric: Executive Presentation Development (PowerPoint)

## Overview
Evaluates model ability to synthesize raw operational/financial data into board-ready slide decks following the **Pyramid Principle** and corporate design standards.

---

## 1. Scoring Dimensions

| Dimension | Weight | Description |
| :--- | :--- | :--- |
| **Action Titles & Narrative Flow** | 30% | Slide headers state the strategic takeaway ("Revenue grew 14% via Enterprise upsell") rather than descriptive topics ("Revenue Analysis"). |
| **MECE Structuring & Synthesis** | 25% | Information is Mutually Exclusive, Collectively Exhaustive. Employs Bottom-Line-Up-Front (BLUF). |
| **Layout & Visual Hierarchy** | 20% | Clear cognitive grouping (2-box, 3-column, comparison matrix). Content fits standard 16:9 widescreen layout without crowding. |
| **Data Visualization Selection** | 15% | Recommends appropriate visual structures (e.g., Waterfall for variance, Stacked Bar for mix shift, Harvey Balls for capability scoring). |
| **Instruction Adherence** | 10% | Matches slide count, bullet limits, target audience tone, and requested output format (bullet outline, XML, or `python-pptx` code). |

---

## 2. Penalty Deductions (Automatic Down-Ranking)
* **-1 Point**: Slide header contains a generic noun label (e.g., *"Market Trends"*, *"Financial Overview"*).
* **-2 Points**: More than 6 bullet points in a single container (violates cognitive load threshold).
* **-3 Points**: Failure to provide structured layout instructions (e.g., dumping a continuous wall of text instead of slide-by-slide split).
